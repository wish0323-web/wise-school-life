# 슬기로운 중학생활

> **한 줄 소개:** 학교생활에 필요한 정보와 개인 기록을 한곳에서 확인하고 관리하는 중학생 생활 도우미입니다.

- **작품 소개 페이지용 짧은 소개글:** 중학생 하루 관리 도우미
- **앱 바로가기:** https://wish0323-web.github.io/wise-school-life/
- **개발자:** 1학년 1반 전재율

---

## 1. 개발 의도

학교생활에 필요한 정보는 시간표, 급식, 학사 일정처럼 여러 곳에 나뉘어 있습니다. 학생은 학교 정보를 확인한 뒤 준비물은 별도 메모장에 적고, 숙제와 시험 날짜는 다시 달력에 기록해야 합니다. 이 과정에서 준비물을 빠뜨리거나 과제 마감일을 놓치기 쉽습니다.

이 불편을 줄이기 위해 **등교 전 준비부터 수업, 급식, 하교 후 자기 관리까지 이어지는 중학생용 생활 관리 웹 앱**을 기획했습니다. 실제 학교 정보는 나이스(NEIS) 교육정보 개방 포털에서 가져오고, 개인 기록은 학생이 직접 관리하도록 구성했습니다.

## 2. 적용 대상

- **사용 대상:** 중학생, 학교생활 정보를 한곳에서 관리하려는 학생
- **사용 상황:** 등교 전 시간표·준비물 확인, 학교에서 급식·학사 일정 확인, 하교 후 숙제·시험·용돈 관리
- **사용 환경:** 스마트폰, 태블릿, 크롬북(디벗)

## 3. 주요 기능과 사용 방법

| 기능 | 설명 |
| --- | --- |
| 학교 검색 | 학교 이름을 검색해 실제 학교를 선택합니다. 학교 정보와 교육청 정보도 확인할 수 있습니다. |
| 시간표·현재 수업 | 학교·학년·반에 맞는 주간 시간표를 확인하고, 현재 수업과 예상 하교 시각을 살펴봅니다. 시간표 일부를 직접 수정할 수도 있습니다. |
| 급식·알레르기 | 오늘·주간·월간 급식, 열량·영양 정보를 확인하고 선택한 알레르기 유발 성분이 포함된 메뉴를 눈에 띄게 표시합니다. |
| 학사 일정 | 학교의 학사 일정을 달력으로 확인하고 시험·행사 날짜를 살펴봅니다. |
| 등교·하교 준비 | 준비물과 할 일을 체크리스트로 관리하고, 나만의 항목을 추가하거나 삭제합니다. |
| 숙제·D-day | 과목별 숙제와 마감일을 기록하고 완료 여부를 표시합니다. 시험이나 개인 목표 날짜도 D-day로 관리합니다. |
| 집중 타이머 | 25분 집중과 5분 휴식으로 구성된 타이머로 공부 시간을 관리합니다. 진행 중인 시간과 완료한 집중 세션 수를 저장합니다. |
| 용돈 관리 | 수입·지출, 소비 분류, 월 예산, 저축 목표를 기록해 소비 습관을 돌아봅니다. |
| 개인 설정·백업 | 글자 크기와 고대비 모드를 조절하고, 현재 프로필의 기록을 백업하거나 복원합니다. |
| 사용자 프로필 분리 | 새 세션에서 닉네임을 다시 선택할 수 있습니다. 닉네임별로 개인 기록을 분리하고 앱 안에서 사용자를 바꿀 수 있습니다. |

**사용 방법**

1. 앱 주소에 접속하고 닉네임을 입력하거나 이름 없이 시작합니다.
2. 학교 이름을 두 글자 이상 입력해 검색하고, 검색 결과에서 우리 학교를 선택합니다. 체험할 때는 샘플 데이터로 둘러볼 수 있습니다.
3. 학교 메뉴에서 학년과 반을 설정하고 시간표를 확인합니다.
4. 등교·학교·급식·하교·생활 메뉴에서 필요한 정보를 확인하고 개인 기록을 추가합니다.
5. 설정에서 화면을 조정하거나 백업 코드를 만들고, 다른 사용자는 **사용자 바꾸기**를 눌러 새 프로필로 전환합니다.

## 4. 기대 효과

- 학교 정보를 확인하기 위해 여러 사이트와 앱을 오가는 시간을 줄일 수 있습니다.
- 시간표·준비물·숙제·학사 일정을 연결해 준비 누락과 마감일 놓침을 예방할 수 있습니다.
- 알레르기 표시를 통해 급식 메뉴를 확인할 때 주의할 성분을 빠르게 찾을 수 있습니다.
- 집중 타이머와 D-day로 학습 계획을 세우고 공부 습관을 기를 수 있습니다.
- 수입·지출과 예산을 기록해 계획적인 용돈 사용을 연습할 수 있습니다.

## 6. 사용한 AI와 제작 과정

- **사용한 AI 도구:** ChatGPT, Claude

- **처음에 AI에게 한 요청(프롬프트):**
  > 중학생이 학교생활에 필요한 시간표, 급식, 학사 일정, 숙제, 준비물, D-day, 용돈 등을 한곳에서 확인하고 관리할 수 있는 웹 앱을 만들어 줘. 나이스 학교 정보를 연동하고 스마트폰에서도 편리하게 사용할 수 있도록 구성해 줘.

- **AI가 만든 결과에서 내가 고치거나 추가한 부분:**
  - 처음 만들어진 화면을 그대로 사용하지 않고 실제 사용 순서에 맞게 학교 선택, 개인 설정, 생활 관리 흐름을 점검하고 정리했습니다.
  - GitHub Pages에 배포한 뒤 학교 검색이 되지 않는 문제를 발견해, 정상 작동했던 Claude 버전의 나이스 API 호출 방식을 기준으로 기존 연결 코드를 다시 비교했습니다.
  - 닉네임이 브라우저의 `localStorage`에 공용으로 저장되어 다른 사용자의 화면에도 남는 원인을 찾아냈습니다. 닉네임은 세션 저장소로 옮기고, 숙제·용돈·알레르기·학교 설정 등은 닉네임별 저장 공간으로 분리했습니다.
  - 현재 사용자를 바꾸는 기능과 기존 기록을 유지하는 프로필 전환 흐름을 추가했습니다.
  - 25분 집중·5분 휴식 타이머를 추가해 앱 안에서 학습 시간도 관리할 수 있도록 확장했습니다.
  - 카드 간격, 글자 위계, 색상 대비, 버튼 상태, 모바일 하단 메뉴와 넓은 화면의 세로 메뉴를 정리해 화면 크기에 따라 사용 흐름이 달라지도록 개선했습니다.
  - 글자 크기·고대비 설정과 현재 프로필 단위 백업·복원 기능을 유지하고, 데이터 설명과 안내 문구를 다듬었습니다.
  - AI는 기획·코드 분석·오류 개선·문서 정리에 활용했습니다. 실행 중 생성형 AI가 답변을 만들어 내는 기능을 구현했다고 주장하지 않고, 학교 정보는 나이스 공개 API에서 조회하도록 구분했습니다.

- **어려웠던 점과 해결한 방법:**
  - **나이스 학교 검색 문제:** 처음에는 중계 서버 또는 브라우저 연결 문제를 의심했지만, 원인을 추측으로 확정하지 않았습니다. Claude에서 정상 작동했던 직접 호출 코드를 비교 기준으로 삼아 나이스 API 주소, 인증키 전달, 응답 처리 흐름을 다시 점검했습니다. 공개 API를 브라우저에서 직접 호출하는 구조를 유지했으며, 실제 배포 환경에서 학교 검색과 급식·시간표 조회를 다시 실행해 확인하는 과정은 필요합니다.
  - **닉네임이 바뀌지 않는 문제:** 기존 `localStorage`는 같은 브라우저 프로필을 이용하는 모든 사용자가 공유하는 저장 공간이었습니다. 닉네임을 세션 단위로 바꾸고, 개인 기록에는 닉네임별 키 공간을 적용했습니다. 계정 인증을 구현한 것은 아니므로 같은 닉네임을 입력하면 같은 로컬 프로필을 사용한다는 점도 화면과 안내에 명시했습니다.
  - **여러 화면 크기 지원:** 모바일 전용 화면에 머무르지 않도록 작은 화면에서는 하단 메뉴, 넓은 화면에서는 세로형 메뉴를 적용하고 표와 입력 영역의 가로 폭을 조정했습니다.

## 8. 개발자 한마디

처음에는 학교 정보를 한곳에 모으는 기능을 만드는 데 집중했지만, 직접 배포하고 사용 흐름을 확인하면서 기능이 많아지는 것만큼 실제로 잘 작동하는지가 중요하다는 사실을 배웠습니다. 학교 검색 오류와 닉네임 공유 문제를 발견했을 때 AI가 만든 코드를 그대로 받아들이지 않고, 다른 버전의 코드와 비교해 원인을 찾고 구조를 다시 설계했습니다. 특히 한 기기를 여러 사람이 사용할 수 있다는 상황까지 생각해 기록을 분리하고, 모바일뿐 아니라 큰 화면에서도 편하게 사용할 수 있도록 개선했습니다. 앞으로도 학생들이 매일 꺼내 쓰고 싶을 만큼 편리하고 정확한 앱으로 발전시키고 싶습니다.
