# 슬기로운 중학생활

> **한 줄 소개:** 시간표·급식·학사 일정과 개인 생활 기록을 한곳에서 관리하는 중학생 생활 도우미입니다.

- **작품 소개 페이지용 짧은 소개글:** 중학생 하루 관리 도우미
- **앱 바로가기:** https://wish0323-web.github.io/wise-school-life/
- **개발자:** 1학년 1반 전재율

---

## 1. 개발 의도

학교생활에 필요한 정보는 시간표, 급식표, 학사 일정처럼 여러 곳에 흩어져 있습니다. 필요한 내용을 확인하려고 사이트와 메모장을 번갈아 사용하다 보면 준비물이나 과제 마감일을 놓치기 쉽습니다. 이 불편을 줄이기 위해 학교 정보 확인부터 개인 생활 기록까지 한곳에서 관리할 수 있는 웹 앱을 기획했습니다.

## 2. 적용 대상

- **사용 대상:** 중학생 및 학교생활 정보를 확인하려는 학생
- **사용 상황:** 등교 전 준비물과 시간표 확인, 학교에서 급식·학사 일정 확인, 하교 후 숙제·일정·용돈 정리
- **이용 환경:** 스마트폰, 태블릿, 크롬북(디벗), 데스크톱 웹 브라우저

## 3. 주요 기능과 사용 방법

| 기능 | 설명 |
| --- | --- |
| 학교 검색 | 학교 이름으로 학교를 검색하고 실제 학교 정보를 선택합니다. |
| 시간표·현재 수업 | 학교·학년·반에 맞는 시간표와 현재 수업, 예상 하교 시각을 확인합니다. |
| 급식·알레르기 | 오늘·주간·월간 급식과 영양 정보를 확인하고 알레르기 성분을 표시합니다. |
| 학사 일정 | 학교 일정을 확인하고 시험·평가 등 중요한 날짜를 살펴봅니다. |
| 등교·하교 준비 | 준비물과 할 일을 체크하고 과목별 준비물을 직접 관리합니다. |
| 숙제·D-day | 과제 내용과 마감일, 시험 및 개인 목표 날짜를 기록합니다. |
| 용돈 관리 | 수입·지출, 예산과 저축 목표를 기록해 소비 습관을 점검합니다. |
| 개인화·백업 | 닉네임, 글자 크기, 고대비 모드를 설정하고 개인 기록을 백업·복원합니다. |

**사용 방법**

1. 앱 주소에 접속한 뒤 원하는 닉네임을 입력하거나 이름 없이 시작합니다.
2. 학교 이름을 두 글자 이상 입력하고 검색 결과에서 학교를 선택합니다. 학교를 찾기 어려우면 샘플 데이터로 기능을 체험할 수 있습니다.
3. 학년과 반, 수업 시작 시각 등 필요한 설정을 입력합니다.
4. 아래 메뉴에서 등교·학교·급식·하교·생활 기능을 이용합니다.
5. 설정 메뉴에서 화면을 조정하거나 기록을 백업·복원합니다.

## 4. 기대 효과

- 학교생활 정보를 한 화면에서 확인해 여러 사이트를 오가는 시간을 줄일 수 있습니다.
- 시간표와 준비물, 숙제 마감일을 함께 관리해 준비 누락을 예방할 수 있습니다.
- 알레르기 설정을 활용해 급식 메뉴의 주의 성분을 빠르게 확인할 수 있습니다.
- 용돈과 저축을 기록하며 계획적인 소비 습관을 기를 수 있습니다.
- 개인 기록을 직접 백업·복원해 기기를 바꾸더라도 필요한 기록을 옮길 수 있습니다.

## 6. 사용한 AI와 제작 과정

- **사용한 AI 도구:** ChatGPT, Claude
- **처음에 AI에게 한 요청(프롬프트):**
  > 중학생이 학교생활에 필요한 시간표, 급식, 학사 일정, 숙제, 준비물, 용돈 등을 한곳에서 확인하고 관리할 수 있는 웹 앱을 만들어 줘. 실제 학교 정보를 연동하고 스마트폰에서도 편리하게 사용할 수 있도록 구성해 줘.
- **AI가 만든 결과에서 내가 고치거나 추가한 부분:**
  - 실제 사용 흐름에 맞게 닉네임 입력과 학교 검색·선택 과정을 정리했습니다.
  - 학교 검색이 정상적으로 되지 않는 문제를 발견하고, Claude에서 작동한 나이스 API 직접 호출 코드를 기준으로 연결 방식을 다시 점검했습니다.
  - 새 나이스 인증키를 적용하고, 이전 브라우저에 저장된 인증키가 새 키를 덮어쓰지 않도록 정리했습니다.
  - 닉네임 입력란의 예시 문구를 제거하고, 별도의 인증키 입력 화면도 없애 처음 사용하는 사람이 더 쉽게 시작하도록 다듬었습니다.
  - 시간표, 급식, 알레르기, 준비물, 숙제, D-day, 용돈, 접근성 설정과 백업 기능을 하나의 앱 흐름으로 정리했습니다.
- **어려웠던 점과 해결한 방법:**
  - GitHub Pages에 게시한 뒤 학교 검색에서 나이스 데이터를 불러오지 못하는 문제가 발생했습니다. 처음에는 연결 중계 서버 문제를 의심했지만, 다른 AI에서 같은 나이스 API가 직접 작동한 것을 확인하고 원인을 단정하지 않기로 했습니다. 정상 작동한 코드의 요청 주소·인증키 전달·응답 처리 방식을 기준으로 기존 코드를 비교하고, 중계 서버에 의존하지 않는 직접 호출 방식으로 정리했습니다.
  - 이전 버전에서 저장된 인증키가 새 인증키보다 우선 적용될 가능성도 확인해 브라우저 저장값을 정리하고 새 설정을 적용하도록 수정했습니다.

## 8. 개발자 한마디

처음에는 학교생활 정보를 한곳에 모으는 기능을 만드는 데 집중했지만, 실제로 배포해 보니 코드가 완성되는 것과 사용자가 문제없이 이용하는 것은 다르다는 점을 알게 되었습니다. 특히 나이스 학교 검색 오류를 해결하기 위해 다른 AI가 만든 코드와 비교하고, 원인을 하나씩 확인하며 연결 방식을 다시 정리했습니다. AI가 만든 결과를 그대로 사용하는 데 그치지 않고 직접 실행해 문제를 찾고 수정하는 과정이 중요하다는 것을 배웠습니다. 앞으로도 실제 학생들이 매일 편하게 사용할 수 있도록 사용성과 정확성을 계속 개선하고 싶습니다.

### 데이터 및 개인정보 안내

- **학교 데이터:** 교육부 나이스(NEIS) 교육정보 개방 포털의 학교정보·급식식단정보·학사일정·시간표를 조회합니다. [나이스 교육정보 개방 포털](https://open.neis.go.kr)
- **개인 기록:** 닉네임, 숙제, 용돈, 취향 등의 정보는 사용 중인 브라우저의 `localStorage`에 저장되며 앱 서버로 전송하지 않습니다. 다른 기기와 자동 동기화되지는 않습니다.
- **인터넷 연결:** 학교의 최신 정보를 조회하려면 인터넷 연결이 필요합니다. 이전에 조회한 일부 정보는 브라우저 캐시에 남을 수 있습니다.
- **샘플 데이터:** 학교 검색 전 체험 기능은 실제 학교 정보가 아닌 예시 데이터입니다.
- **알레르기 정보:** 표시 내용은 참고용입니다. 실제 식재료와 조리 과정은 학교 급식실에 확인해야 합니다.
- **인증키 안내:** 현재 버전은 나이스 인증키를 브라우저 코드에서 사용합니다. GitHub 저장소를 공개하면 인증키도 소스코드에서 확인될 수 있으므로 요청 한도 관리에 유의해야 합니다.
