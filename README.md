## 1. 개발 의도

시간표, 급식, 학사 일정, 숙제와 준비물은 서로 다른 곳에서 확인해야 하므로 필요한 정보를 놓치기 쉽습니다. 학교생활에 자주 쓰는 정보를 한 화면에 모으고 개인 기록까지 함께 관리할 수 있도록 제작했습니다.

## 2. 적용 대상

- **사용 대상:** 초·중·고등학생
- **사용 상황:** 등교 전 시간표와 준비물 확인, 점심시간 급식 확인, 하교 후 숙제와 용돈 관리
- **이용 환경:** 스마트폰, 태블릿, 크롬북(디벗), 데스크톱 웹 브라우저

## 3. 주요 기능과 사용 방법

| 기능 | 설명 |
| --- | --- |
| 맞춤형 시작 화면 | 첫 실행 시 닉네임을 설정합니다. 같은 브라우저에서는 다음 접속에도 유지됩니다. |
| 학교 검색 및 정보 | 학교 유형을 선택해 나이스 학교 정보를 검색하고, 학교명과 주소를 확인한 뒤 선택합니다. |
| 시간표 및 현재 수업 | 학년·반과 수업 시간을 설정하고 주간 시간표와 현재 수업을 확인합니다. |
| 급식 및 알레르기 | 오늘·주간·월간 식단을 확인하고 선택한 알레르기 유발 성분을 표시합니다. |
| 학사 일정과 숙제 | 학사 일정, 개인 일정, 시험 D-day와 과제 마감일을 관리합니다. |
| 등교·하교 준비 | 준비물과 개인 체크리스트를 확인하고 완료 여부를 기록합니다. |
| 용돈 및 저축 | 수입·지출, 월 예산과 저축 목표를 관리합니다. |
| 접근성 및 백업 | 글자 크기와 고대비 모드를 조절하고 개인 기록을 백업·복원합니다. |

**사용 방법**

1. 앱 주소에 접속한 뒤 닉네임을 설정합니다. 닉네임 없이 시작할 수도 있습니다.
2. 학교 유형을 선택하고 학교 이름을 검색합니다.
3. 검색 결과에서 학교명과 주소를 확인한 후 해당 학교를 선택합니다.
4. 학년·반과 수업 시간을 설정하고 급식 알레르기 항목을 선택합니다.
5. 아래쪽 메뉴에서 등교, 학교, 급식, 하교, 생활 기능을 이용합니다.

### 데이터 및 개인정보 안내

- **학교 데이터:** 교육부 나이스(NEIS) 교육정보 개방 포털의 학교정보, 급식식단정보, 학사일정 및 시간표를 사용합니다. ([나이스 교육정보 개방 포털](https://open.neis.go.kr))
- **개인 기록:** 닉네임, 취향, 숙제, 용돈 등의 기록은 현재 브라우저의 `localStorage`에 저장합니다. 앱 운영 서버로 전송하지 않으며 다른 기기와 자동 동기화되지 않습니다.
- **나이스 인증:** 인증키를 `index.html`의 `NEIS_API_KEY` 상수에 직접 지정해 나이스 API를 호출합니다. 별도의 Cloudflare Worker나 서버 설정은 필요하지 않습니다.
- **인증키 공개 안내:** 이 앱은 GitHub Pages 정적 웹앱이므로 인증키가 공개 저장소의 소스 코드와 브라우저 개발자 도구 및 네트워크 요청에 표시됩니다. 공개된 키를 다른 사람이 사용할 수 있고 요청 한도가 소진될 수 있습니다. 이 점을 이해한 상태에서 사용해야 하며, 필요하면 나이스 포털에서 키를 재발급해야 합니다.
- **오프라인 이용:** 이전에 조회해 브라우저에 저장한 자료 일부를 표시할 수 있습니다. 새로운 자료를 조회하려면 인터넷 연결이 필요합니다.
- **급식 정보:** 알레르기 표시는 참고용입니다. 실제 성분과 조리 과정은 학교 급식실에 확인해야 합니다.
- **예상 하교 시각:** 공식 안내가 아닌, 사용자가 설정한 수업 시간과 시간표를 바탕으로 계산한 값입니다.

## 4. 기대 효과

- 학교생활에 필요한 정보를 한곳에서 확인해 시간표와 준비물을 놓치는 일을 줄일 수 있습니다.
- 알레르기 설정을 통해 급식 메뉴의 주의 성분을 빠르게 확인할 수 있습니다.
- 숙제와 일정을 관리해 과제 마감일을 놓칠 가능성을 줄일 수 있습니다.
- 용돈과 저축 기록을 통해 계획적인 소비 습관을 기를 수 있습니다.
- 개인 기록을 기기에 저장하고 백업할 수 있어 기록 관리가 편리합니다.

## 6. 사용한 AI와 제작 과정

- **사용한 AI 도구:** ChatGPT
- **처음에 AI에게 한 요청(프롬프트):**
  > 기존 프로젝트를 참고해 첫 화면에서 닉네임을 설정할 수 있도록 하고, 디자인을 세련되게 개선해 주세요. 학교생활에 필요한 기능은 유지하되 과도한 기능은 추가하지 말고, GitHub 공개에 적합하도록 README도 작성해 주세요.

**AI가 만든 결과에서 내가 고치거나 추가한 부분**

- 기존 기능을 학교생활 정보와 개인 생활 관리로 구분했습니다.
- 첫 화면에 닉네임 입력 단계를 추가하고 브라우저 저장 방식을 적용했습니다.
- 학교 선택 과정에서 발생하던 화면 전환 오류를 수정하고 검색 결과에 학교 유형과 주소를 표시하도록 개선했습니다.
- 샘플 학교와 샘플 데이터를 제거했습니다.
- 별도 인증키 입력 UI와 Worker 설정을 제거하고, 나이스 인증키를 앱 코드에서 직접 전달하도록 변경했습니다.
- 모바일 화면과 전체 디자인의 색상, 간격, 카드, 메뉴 스타일을 통일했습니다.

**어려웠던 점과 해결한 방법**

- 학교 선택 후 설정 화면의 이벤트 연결 과정에서 존재하지 않는 인증키 입력 요소를 참조해 화면 전환이 중단될 수 있었습니다. 해당 참조를 제거하고 학교 선택 이후 초기화 흐름을 정리했습니다.
- 나이스 API는 인증키를 포함해 요청하며, 한 번에 최대 100건을 요청합니다. 응답이 페이지 크기에 도달하는 기간 조회는 날짜 범위를 나누어 누락 가능성을 줄입니다.
- 인증키를 정적 웹앱에서 직접 전달하도록 구성했습니다. 이 방식은 별도 서버가 필요 없지만, 공개 저장소와 브라우저에서 키가 노출된다는 점을 README에 명시했습니다.
